١.في البداية نزل بيئة بايثون 
وها ادخل الى المشروع الذي في الغيت هاب واخذه وادخل الى الترمينل ونفذ امر :
pip install -r requirements.txt
 هاذا امر تنزيل كل المكتبات المستعملة في ملف دجانجو يجب تحميلها كي تعمل المكتبات في بايثون .
٢.تالياً سوف يرسل لكم قاعدة البيانات بورستقري على هيئة ملف يجب ان تحمل بوستقري من موقعهم الرسمي لن يتجاوز نصف جيجا ؛ يعد ان تثبته اتركه على الاعدادت الافراضية لا ينصح بتغيير البورت المستعمل في مرحلة التطوير وبعدها ابعدها من البرنامج سوي فتح للقاعدة التي تم ارسالها لكي تفتح لك كل الجداول والخلايا والبيانات .
٣.ادخل هل مسار سرفر  دجانجو بامر cd
اسم الملف ستجد داخله مجلد باسم
api وغيره ونفذ امر
python manage.py migrate
هاذا يسوي بناء وترحيل الجداول قبل تشغيل السيرفر 
وبعدها امر 
 python manage.py runserver
هاذا الامر يستعمل لتشغيل سرفر دجانجوا الذي سيتعامل معا انتقال البيانات بين الواجهات وقاعدة البيانات.
٤.بعدها سوي ترمينل ثانية من تبويب الترمينل سترى في الجنب الايمن ايقونه لمربع مقسوم نصفين على شكل صفحتين تاكد انك بمسار المشروع الرئيسي nopp ونفذ الامر 
Flutter run

وذا شرح مبسط لملفات دجانجو 
student_project/                 # مجلد المشروع الرئيسي (يحتوي على كل ملفات المشروع)
│
├── manage.py                    # ملف التحكم والإدارة الأساسي (لتشغيل السيرفر وتنفيذ الأوامر)
│
├── student_project/             # مجلد الإعدادات الرئيسي للمشروع (Settings & Configuration)
│   ├── __init__.py              # ملف فارغ يخبر بايثون أن هذا المجلد يعتبر حزمة (Package)
│   ├── settings.py              # ملف الإعدادات والضبط الشامل للمشروع (قاعدة البيانات، التطبيقات، الأمان)
│   ├── urls.py                  # الروابط الرئيسية للمشروع (توجيه الروابط إلى التطبيقات المختلفة)
│   ├── asgi.py                  # إعدادات الاتصال غير المتزامن (Asynchronous - للبث المباشر والـ WebSockets)
│   └── wsgi.py                  # إعدادات النشر التقليدية (Web Server Gateway Interface - لنشر المشروع على سيرفر حقيقي)
│
└── api/                         # تطبيق الـ API الخاص بالربط مع الفلاتر
    ├── __init__.py
    ├── admin.py                 # تسجيل النماذج لظهورها في لوحة تحكم دجانجو الافتراضية
    ├── apps.py                  # إعدادات وتكوين تطبيق الـ api نفسه
    ├── models.py                # جداول قاعدة البيانات (Database Models - مثل الطلاب والمعلمين)
    ├── serializers.py           # ترجمة بيانات الجداول إلى صيغة JSON والعكس (جسر التواصل مع Flutter)
    ├── views.py                 # المنطق البرمجي ومعالجة طلبات الـ API (GET, POST, PUT, DELETE)
    ├── urls.py                  # مسارات وروابط الـ Endpoints الخاصة بهذا التطبيق فقط
    └── migrations/              # مجلد تتبع وتحديثات قاعدة البيانات (ملفات الترحيل Migration Files)
